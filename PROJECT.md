# Project specification and implementation

The authoritative specification is [VirtuosoTranscribe_PROJECT.md](VirtuosoTranscribe_PROJECT.md).

The V1 M0–M10 engineering pipeline is implemented, including learned single/dual/conditioned Transformers, constrained autoregression, reranking, audio, experiments and the local demo. See [README](README.md) for commands, [implementation status](docs/implementation_status.md) for measured evidence and research acceptance limits, and [dataset card](docs/dataset_card.md) for provenance.

V2/V3 stretch goals remain subsequent research. Software completion does not imply large-corpus generalization or human artistic approval.
